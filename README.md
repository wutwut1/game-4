# Play ball 🏀

เกม AR แบบ 2D: ใช้นิ้วโป้งกับนิ้วชี้จีบลูกบอลที่พื้นขึ้นมา แล้วปล่อยหรือโยนให้ลงห่วงที่ลอยอยู่บนจอ โดยมีภาพจากกล้องเป็นพื้นหลัง เล่นได้ทั้งบนคอมพิวเตอร์และมือถือ

## วิธีเล่น
- ยกมือให้กล้องเห็น บนจอจะมีจุดขึ้นที่ปลายนิ้วโป้งและปลายนิ้วชี้
- จีบนิ้วเข้าหากันใกล้ลูกบอลเพื่อหยิบ แล้วแบนิ้วออกเพื่อปล่อย
- บอลมี 10 ลูก และมีเวลา 1:30 นาที
- ลงห่วงติดกันภายใน 4 วินาทีจะได้คอมโบ (คะแนนคูณสูงสุด x5)
- ลงห่วงโดยไม่โดนขอบ (SWISH) ได้โบนัสเพิ่ม 50 คะแนน
- ระวัง **ห่วงผี** 👻 (ขอบสีม่วงเรืองแสง มีหนาม และมีผีลอยอยู่ด้านบน) ถ้าโยนลงจะโดนหักคะแนนแบบสุ่ม 50–200 และคอมโบหลุด
- ถ้าไม่มีกล้อง เล่นด้วยเมาส์หรือทัชสกรีนได้
- คีย์ลัด: `P` / `Esc` หยุดเกม, `M` เปิด/ปิดเสียง, `N` เปิด/ปิดเพลง

## วิธีเปิดเกม
เบราว์เซอร์จะยอมให้ใช้กล้องเฉพาะเมื่อเปิดผ่าน **https://** หรือ **localhost** เท่านั้น ดับเบิลคลิกเปิดไฟล์ `index.html` ตรง ๆ จะใช้ไม่ได้

- **บนคอม:** ติดตั้งส่วนเสริม *Live Server* ใน VS Code แล้วคลิกขวาที่ `index.html` เลือก **Open with Live Server**
- **บนมือถือ:** เปิด GitHub Pages ของ repo นี้ แล้วเข้าลิงก์ `https://wutwut1.github.io/game-4/`

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ, HUD, หน้าเมนู/หยุด/จบเกม |
| `css/style.css` | หน้าตา UI ที่ปรับขนาดตามจอ |
| `js/config.js` | **ตั้งค่าเกมทั้งหมด** เช่น เวลา จำนวนบอล ฟิสิกส์ ความไวของการจีบ |
| `js/main.js` | จุดเริ่มต้น ผูกปุ่มและคีย์ลัด |
| `js/game.js` | ลูปเกม, สถานะเกม, หยิบ/โยน, คะแนน, การวาด |
| `js/ball.js` | ลูกบอลและฟิสิกส์ |
| `js/hoop.js` | ห่วงที่ลอยไปมาและการตรวจว่าลงห่วง |
| `js/input.js` | ตรวจจับมือจากกล้อง (MediaPipe) และเมาส์/ทัช |
| `js/audio.js` | เสียงเอฟเฟกต์และเพลงพื้นหลัง สร้างด้วยโค้ดทั้งหมด |
| `js/effects.js` | พลุกระดาษและตัวเลขคะแนนลอย |

เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม
